# perception — 인지 (하이레벨 담당)

카메라(RealSense D455)로 신호등·주차 라바콘·차선을 인식하는 노드.

## 만들 노드

### 1. 신호등 인식 (최우선)
- 입력: D455 컬러 이미지
- 처리: YOLO(ultralytics)로 신호등 검출 → 색 판단
- 출력: `/perception/sign` (`std_msgs/String`) — `red`/`yellow`/`green`/`left`/`none`
- GTX 1650 4GB → YOLOv8n 또는 s 모델 권장

### 2. 주차 라바콘 인식 (2순위)
- 주차 미션에서 라바콘 위치 검출
- 출력 형식은 판단 담당과 협의 후 확정 (일단 신호등 먼저)

### 3. 차선 안전벨트 (3순위, 여유 시)
- BEV 변환 → 차선 검출 → 오프셋·조향각 계산
- 출력: `/perception/lane` (`std_msgs/Float32MultiArray`) = [오프셋(m), 조향각(deg), 유효성]
- **주의: HSV 임계값은 실제 코스에서 반드시 재캘리브레이션.** 시뮬 값 그대로 쓰면 안 됨.

## 지켜야 할 것
- 출력 토픽 이름·타입은 `docs/interface.md` 그대로. 절대 임의 변경 금지.
- 상대 노드 없이 테스트: `common/`의 가짜 판단 노드로 확인.

## 우선순위
신호등 → 주차 → 차선. 신호등부터 확실히 동작시키고 다음으로.
