# 준비 유지형 수동 조작

사용자가 준비한 빈 공간과 차단 담당자 아래 수동 시험용 실제 출력 펌웨어다. 중립 확인→명시적ARM 한 번 뒤, 전진·후진은 키를 누르는 동안 앞뒤PWM110으로 계속 작동하며 좌우 조향을 동시에 요청할 수 있다. 키가 없으면 출력0으로 멈추면서 준비 상태는 유지된다. 조향은PWM60이며 한 번 누를 때 최대1000ms 또는 시작ADC대비절대변화100counts까지만 작동한다. 조향 보호가 작동해도 함께 요청된 구동은 계속된다.

각 축은 독립적으로 추가하거나 놓을 수 있다. 같은 축의 반대 방향은 그 축의0 명령이 먼저 보드에 도착해야 한다. 정지 버튼·Esc·창 이탈·오류·150ms 통신 만료는DISARM한다. 조향 보호 한계에 도달하면 조향 출력만 막고 구동은 유지한다. ADC 상단에서는 값이 더 커지는 방향만, 하단에서는 값이 더 작아지는 방향만 막아 중앙으로 복귀할 수 있다.

TYPE144/flags38→102이며 actual_drive/steer는 게이트가 적용한 출력명령이고 물리 측정값이 아니다.

Core복사본의150ms통신기한·50ms상태주기·EEPROM부팅식별을 유지한다. 2026-09-06 현장에서 기존0~11영역의 보수값 쓰기 실패를 실제 확인하고 원본을 보존한 채 새 예약영역16~27을 사용한다. 전원/E-stop물리입력·하드웨어watchdog없음, CPU정지/재부팅상태·물리제동보장은별도다. 상대ADC100는중앙/끝/각도보정이 아니고 ADC레일<=1/>=1022는 출력거부조건이다.
