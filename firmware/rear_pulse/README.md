# 뒤 구동 모터 단발 시험

앞 모터 단발 펌웨어에서 활성 채널만 뒤 모터(D44 PWM30, D23 LOW, D24 BRK LOW)로 바꾼 별도 빌드다. 앞 모터와 조향은 PWM0/BRK HIGH 고정. 동일 게이트의100ms 소프트웨어 제한·부팅당1회·재사용 불가 조건을 유지한다.

상태 TYPE132, flags34→98, actual_drive1은 뒤 모터 출력 명령 활성이다. 기존 앞 엔코더 값은 뒤 회전의 증거가 아니다. Core/PulseGate와 검사는 앞 펌웨어 원본과 바이트가 같다. type132만 스케치 안에서 별도 지정한다. 상세 해시와 검사·빌드는 build_provenance.json을 따른다.

하중 받침/차단 담당자 대기 조건의 공중 단발 시험 전용이며 물리 피드백·watchdog이 없다. 이 구현 작업에서는 하드웨어에 접근하지 않았다. 실제 보드 상태와 구동 결과는 프로젝트 docs/STATUS.md를 따른다.
