# 조향 단발 시험

D11 PWM30/255, D6 LOW(원본 좌 조향 설정), D7 BRK LOW만 단1회 허용하는 공중 시험 펌웨어다. 앞·뒤 구동은 PWM0/BRK HIGH.100ms 또는 시작 ADC 대비 절대변화12counts 중 먼저 도달하는 조건에서 종료하며, 반복/재ARM은 재출력하지 않는다.12counts는 상대 시험 제한이며 실측 조향 끝/중앙/각도가 아니다. 시작 ADC<=1 또는>=1022이면 출력 없이 시도를 소비한다.

상태 TYPE133, flags36→100, actual_steer-1은 조향 PWM명령 활성이고 actual_drive는항상0이다. Core는 검증본의 동일 사본이며 게이트만 조향/상대ADC 조건으로 작성했다. 측정된507/508 등은 하드코딩하지 않았다.

물리전원/E-stop입력·watchdog 없음, 부팅당래치리셋/CPU정지한계는 이전단발과같다. 받침/차단담당자대기조건을 확인한 제한시험 전용이다. 구현작업에서장치접근·업로드는하지않았다. 검사/HEX근거는 build_provenance.json, 실제보드상태는 프로젝트 docs/STATUS.md를 따른다.
