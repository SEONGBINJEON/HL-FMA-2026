# arduino — 저수준 제어 (로우레벨 담당)

Arduino Mega 2560 펌웨어. 노트북(판단)에서 목표 속도·조향각을 받아
실제 모터·조향을 PID로 굴리고, 엔코더 값을 다시 올려보낸다.

## 만들 것

### 1. 시리얼 통신 (최우선)
- 노트북 ↔ 메가 시리얼 프로토콜 정의 (총괄과 협의)
- 수신: 목표 속도(m/s), 목표 조향각(deg) — `/cmd/drive`에서 옴
- 송신: 엔코더 오도메트리 → 노트북에서 `/sensor/odom`으로 변환·발행
- **타임아웃 세이프티: 0.5초 이상 명령 없으면 속도·조향 0 정지**

### 2. 속도 PID (최우선)
- F8 순정 엔코더로 실제 속도 측정
- 목표 속도에 맞춰 HENES 드라이버로 모터 출력 PID 제어

### 3. 조향 PID (2순위)
- 조향 각도 피드백(가변저항 등)을 읽어 목표 조향각으로 서보 PID
- **조향 부호: 좌회전 +, 우회전 −** (`docs/interface.md`)

### 4. 초음파 (3순위)
- 전·후방 초음파 거리 측정 → 노트북으로 송신 (`/sensor/ultrasonic`)

## 지켜야 할 것
- 단위: 속도 m/s, 조향각 deg. 부호 규칙 엄수.
- **12V 순정 모터에 24V 직결 주의** — HENES 드라이버가 강압하는지 반드시 확인 후 통전.

## 단독 테스트
- 노트북 없이: 시리얼 모니터로 "속도 0.5, 조향 10" 수동 입력 → 모터 도는지 확인.

## 우선순위
시리얼+타임아웃 → 속도 PID → 조향 PID → 초음파.
