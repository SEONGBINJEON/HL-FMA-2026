# 외부 자료와 자체 작업 구분

## HYPER

로컬 참고 프로젝트의 README에 명시된 출처: [qndks11/HYPER](https://github.com/qndks11/HYPER).

경로·미션 구성·기존 신호 모델을 재사용/참고했다. 일부 adapter에는 HYPER 판단 방법을 재구현하거나 통합한 부분이 있으며, 자체 신규 학습 모델로 소개하지 않는다. 차량별 제어·통신·좌표/장착 적용·미션 통합·운영 절차·검사·회고와 구분한다.

이 저장소에는 HYPER 원 저장소 전체, 모델 가중치, waypoint CSV, 대회 PDF와 외부 제공 사진 묶음을 포함하지 않았다. 로컬 자료만으로 해당 원본의 재배포 라이선스를 확정하지 못했다. 취득·재사용 시 원저작자의 조건을 별도로 확인해야 한다.

## 기타 의존성

Python 라이브러리, DepthAI, OpenCV, NumPy, pygnssutils, Ultralytics, RPLIDAR SDK 등은 해당 프로젝트의 라이선스를 따른다. 가상환경·SDK 바이너리·학습 가중치를 이 저장소에 함께 배포하지 않는다. 저장소 전체를 임의의 단일 오픈소스 라이선스로 선언하지 않았다.

## 자료 보존

경기 영상·사진·개인 대화·인증파일·원시 로그는 로컬에서 보존한다. GitHub에는 선별된 결과 수치·분석 코드·설명을 기록했다. 원본 소유권이나 개인정보 검토 없이 대용량 자료를 통째로 공개하는 저장소가 아니다.
