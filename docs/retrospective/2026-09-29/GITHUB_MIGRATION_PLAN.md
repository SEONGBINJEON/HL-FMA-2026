## 교체 방식

기존 커밋을 부모로 하는 새 커밋에서 초기 설계 문서와 폴더를 정리하고 아래 내용을 반영한다. 이렇게 하면 현재 화면의 내용은 새 자료로 바뀌고 과거 이력은 남는다. 저장소 삭제·재생성 또는 강제 이력 덮어쓰기는 필요 없다. 원격 반영 시 기존 main이 바뀌지 않았는지 확인하고 일반 변경으로 적용한다.

```text
README.md                              프로젝트 소개·실제 결과·읽기 순서
docs/retrospective/2026-09-29/           준비 과정·설계·실패 분석·검증 범위
docs/analysis/competition_archive_2026-09-29/
                                       근거 추출·재현 도구와 결과
tools/ scripts/ tests/                  자체 구현·운영·검사 소스
firmware/                              제어 소스와 설명, 빌드 결과 제외
config/                                인증정보가 없는 차량별 설정만 선별
requirements-*.txt                     기존 의존성 기록
```

초안의 README에서 대회 종료와 실제 도달 구간을 먼저 밝힌다. 기획상의 ROS2/RealSense/센서융합을 최종 구현 성과로 쓰지 않는다. 주행 명령을 설치 직후 실행하는 안내로 배치하지 않는다.

## 초안의 재현 한계

이 저장소는 대회 종료 후 문서·소스를 정리한 기록용 저장소다. 원본 런타임은 로컬 보정 파일, HYPER 경로/모델, 빌드한 호스트 라이브러리와 장치 환경에 의존한다. 이를 제외한 상태에서 clone만으로 실행 가능하다고 표시하지 않는다. 설치/재현 패키지를 완성하려면 해당 의존성의 취득·빌드·설정 방법을 검토해 추가해야 한다.

비밀 패턴 검사는 선별 소스의 1차 점검이며 모든 개인정보·권리 검토를 대신하지 않는다. 기존 커밋 이력을 보존하고 비공개 설정을 유지한다. 원시자료와 외부 모델은 이 저장소에 포함하지 않았다.
