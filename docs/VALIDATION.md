# 정리 저장소의 오프라인 확인

2026-09-29, 복사된 저장소 사본 자체를 cwd로 사용했다. 차량·네트워크·인증파일 접근 없이 다음을 확인했다.

| 검사 | 결과 |
|---|---|
| 첫 신호등 복구 잠금 합성 분리 재현 | exit0. 정상 빨강→초록 재개와 잠금 이후 재개 불가를 구분 |
| 호스트 C++ 조향 라이브러리 빌드 | exit0. 포함된 build.sh와 C++ 소스만으로 공유 라이브러리 생성 |
| 포함 파일 SHA256 | PACKAGE_MANIFEST.json으로 대조 |
| Markdown 파일 링크 | 배포 사본 기준으로 누락 링크 점검 |

재현 명령은 [REPRODUCIBILITY](REPRODUCIBILITY.md)에 있다. 이 검사는 원본 전체 회귀·센서 연결·실차 주행 검증이 아니다. 생성된 빌드 바이너리와 실행 로그는 Git 업로드 목록에서 제외하고, 요약 근거만 archive_validation_20260929.json에 보존한다.
